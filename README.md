## 📂 Featured Core Projects

### 🏗️ [GNS3-Topology-JR7](https://github.com/KDIAS-JR7/GNS3-Topology-JR7)
A production-grade, highly redundant three-tier hierarchical enterprise network simulation. Engineered core, distribution, and access layout architectures featuring strict VLSM breakdowns, active out-of-band management channels (VLAN 99), cross-backbone EtherChannel link aggregation bundles, and HSRP redundant gateways.

### 🤖 [Ansible-JR7](https://github.com/KDIAS-JR7/Ansible-JR7)
An advanced Infrastructure-as-Code (IaC) automation repository containing 18 production-ready playbooks engineered to scale configuration management, policy enforcement, and live operational testing. Features unified syslog telemetry targeting upstream collectors, dynamic loops, drift capture diagnostics, and strict idempotency handling.

### 🔀 [L3-InterVlanRouting-JR7](https://github.com/KDIAS-JR7/L3-InterVlanRouting-JR7)
A Cisco Packet Tracer lab implementing Layer 3 Inter-VLAN routing. Configured core Multilayer Switches (SVI), access topologies, DHCP pooling, and access lists to handle secure, high-throughput traffic distribution across segmented broadcast domains.
